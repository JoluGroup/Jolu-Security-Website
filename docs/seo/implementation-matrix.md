## 7. Claim-sensitive keyword classification

### Method

Implemented once, in `lib/seo/claim-classifier.ts`, and used by the generator, the data file and the tests (`scripts/seo/classify-cli.mjs` runs the same code for the generator). A keyword is claim-sensitive when writing it into public copy would assert something that needs evidence or owner approval (`lib/claims.ts`: every claim is still "needs-evidence").

1. Each keyword is matched case-insensitively, on whole words, against the category rules below.
2. Judgment rules then add or remove a category where a word match is wrong or too narrow.
3. The result is stored per keyword (`claimSensitive` and `classification`) in `lib/seo/workbook-keywords.ts`, and a test re-runs the classifier over all 311 keywords and fails if the stored data is stale.

Reproduce: `python3 scripts/seo/build-seo-data.py <workbook.xlsx>` then `git diff` (empty if nothing changed).

### Category rules (whole-word, case-insensitive)

- **licensing**: `/\b(licen[cs]e[ds]?|licen[cs]ing|psra|registered|registration|accredited|accreditation|certified|certification|certificate|compliant|compliance)\b/i`
- **superlative or quality**: `/\b(best|top|leading|trusted|reliable|reputable|professional|affordable|cheap|cheapest|quality|premier|experienced|trained|vetted|insured|guaranteed)\b/i`
- **availability or response time**: `/\b(24\/7|24 ?hours?|24-hours?|round[- ]the[- ]clock|emergency|rapid|fast|quick|immediate|same[- ]day|response time|armed response|open now)\b/i`
- **pricing**: `/\b(costs?|prices?|pricing|rates?|quotations?|quotes?|fees?|how much)\b/i`

### Judgment rules

- **J1-near-me** (include - local presence or proximity): `/\b(near me|nearby|closest|nearest)\b/i`. A page answering 'near me' implies a verified local office and reachable service area. Included so it is not written into copy before the office details are verified; no word rule would catch it.
- **J2-best-placement** (exclude - superlative or quality): `/\bbest\b.*\bplacement\b/i`. 'best CCTV placement for a home' asks for technique advice. 'best' does not describe the company, so no quality claim is made. Excluded from the superlative category.

- Keywords classified: 311.
- **Claim-sensitive keywords: 30** (28 by word rule, 2 by judgment inclusion).
- By category (a keyword can be in more than one): availability or response time 9, licensing 3, local presence or proximity 2, pricing 11, superlative or quality 5.
- By where the keyword is planned: homepage 5, planned service/location/industry pages 21, editorial 4.
- Matched a word rule but excluded by judgment: 1 (KW-301 best cctv placement for a home).
- Earlier figures: "31" (Milestone 5 report) could not be reproduced and is withdrawn; "29" (Milestone 5A audit) used a narrower word list and no judgment rules. The count above is the recalculated figure under the stated method.

### Judgment-dependent and deferred classifications

- Included by judgment (J1, "near me"): KW-086 security company near me, KW-087 security guard company near me.
- Excluded by judgment (J2): KW-301 best cctv placement for a home.
- Informational pricing and licensing topics (for example "how much does ... cost", "psra licence") are classified as claim-sensitive by word rule. The topic is fine for an expert-reviewed article; the claim risk is any statement of a price, range or licence status, so these are deferred until the editorial fact-check.
- "corporate" is not matched as "rate" (whole-word matching).
